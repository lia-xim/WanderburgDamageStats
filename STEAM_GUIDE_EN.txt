TITLE
Wanderburg Damage Stats – Live DPS and Upgrade Recommendations

SHORT DESCRIPTION
A small unofficial mod that shows which weapons are carrying your run and helps compare numerical upgrade choices.

LANGUAGE
English

Modding or Configuration

SECTION 1 — What this mod does

[h1]What this mod does[/h1]

Wanderburg Damage Stats is a small experiment I made because I wanted more useful information when choosing upgrades.

During a run, it shows:

[list]
[*]actual damage per second over the last 20 seconds
[*]each mounted weapon's share of that damage
[*]a comparison of the three cards on the upgrade screen
[*]an estimated recommendation for normal numerical upgrades
[/list]

The recommendation uses your current run instead of treating every weapon as equally important. If one weapon is doing most of your damage, an upgrade for that weapon usually receives more weight.

Special, legendary, and utility effects are harder to compare reliably. When duration, range, projectile speed, cooldown utilization, or another important effect remains outside the model, the overlay labels its recommendation as a "damage pick" rather than claiming it is the universally best card.

[b]This is an early alpha for Wanderburg EA 0.9.8 on Windows.[/b]

SECTION 2 — Installation

[h1]Installation[/h1]

The mod uses BepInEx 6 for Unity IL2CPP, Windows x64.

[olist]
[*]Install BepInEx 6 using the [url=https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html]official IL2CPP installation guide[/url].
[*]Start Wanderburg once through Steam, then close it. This lets BepInEx create its folders.
[*]Download the newest [url=https://github.com/lia-xim/WanderburgDamageStats/releases/latest]WanderburgDamageStats ZIP[/url] and extract it.
[*]Copy [code]WanderburgDamageStats.dll[/code] into [code]Wanderburg Game\BepInEx\plugins\[/code].
[*]Start Wanderburg normally through Steam.
[/olist]

If you do not know where Wanderburg is installed, right-click the game in your Steam Library and choose [b]Manage → Browse local files[/b].

The overlay should appear in the upper-left corner after starting a run. Press [b]F8[/b] to hide or show it.

[b]Please launch the game through Steam.[/b] Starting Wanderburg.exe directly did not initialize Steamworks correctly in my test, which caused Steam statistics and leaderboards to stop updating for that run.

SECTION 3 — How it was made

[h1]How it was made[/h1]

Wanderburg does not currently provide an official mod SDK or Workshop integration, so this is a code mod rather than a normal Steam Workshop item.

The game is built with Unity IL2CPP. I used BepInEx to load a small C# plugin and inspected the game's generated IL2CPP types to find the existing run statistics and upgrade-card UI.

The plugin reads the game's [code]StatisticsQuery.CurrentRun[/code] counters at short intervals. It calculates the change in total damage between samples, groups it by weapon, and turns that into a rolling 20-second DPS view.

On the upgrade screen, it reads the text and numerical values already assigned to the three cards. Direct damage changes are combined with the weapon's current damage share. Cooldown and charges are treated conservatively because their value depends on actual usage. Duration, size, range, and projectile speed remain outside the guaranteed DPS estimate.

The plugin does not change weapon damage, combat rules, save data, or Steam statistics. Its only Harmony patch observes the upgrade-card UI so it knows which choices are currently visible.

SECTION 4 — Limits and removal

[h1]Limits and removal[/h1]

This is an unofficial community project and is not affiliated with or endorsed by Randwerk. Game updates can rename or change internal code, so the mod may need an update after a new Wanderburg version.

The recommendation is an estimate. Positioning, enemy types, range, area coverage, and unusual card interactions can make a situational upgrade better than the numerical winner.

To remove the mod, close the game and delete:

[code]BepInEx\plugins\WanderburgDamageStats.dll[/code]

If it does not load, open [code]BepInEx\LogOutput.log[/code] and search for [code]Wanderburg Damage Stats[/code].

Feedback and bug reports are welcome on the [url=https://github.com/lia-xim/WanderburgDamageStats/issues]GitHub issue tracker[/url].
